# 1. Предложение проекта

**Название:** Разработка игровой платформы для обучения финансовой грамотности для студентов
**Команда:** Бабаханов С.А. (SE-2411), Тельман Ж.Е. (SE-2411)
**Руководитель:** Шутеева Гулнур Сериковна
**Документ версии:** 1.1 (к предзащите 24.10.2026; изменения: раздел 1.4 и 1.6 — личные финансы, аватар, сценарии)

## 1.1. Проблема

Студенты самостоятельно управляют стипендией, подработкой, рассрочками и кредитами, но знания о финансах получают с опозданием. Ошибки в этих решениях (накопления без резерва, переплата по рассрочке, реакция на мошеннические сообщения) дорогие. Традиционные формы обучения — лекции и тесты — не показывают последствий решений и слабо вовлекают студентов.

## 1.2. Цель

Создать игровую платформу, в которой студент учится финансовой грамотности через решения в смоделированных жизненных ситуациях, а преподаватель видит типичные ошибки своей группы.

## 1.3. Задачи

1. Провести анализ предметной области, литературы и существующих решений.
2. Подтвердить актуальность интервью с потенциальными пользователями.
3. Обосновать выбор технологий.
4. Сформулировать функциональные и нефункциональные требования с критериями приёмки.
5. Спроектировать архитектуру (контекст, use case, компоненты, модель данных).
6. Разработать интерактивный прототип ключевых сценариев.
7. Реализовать клиент (Flutter) и сервер (Node.js, PostgreSQL) с серверным расчётом последствий решений.
8. Реализовать Teacher Mode с аналитикой ошибок группы.
9. Провести верификацию: тесты, сверка расчётов с эталонами, пилот с группой студентов.

## 1.4. Ожидаемые результаты

- Мобильное приложение (Flutter), интегрированное с сервером по REST API.
- Личный профиль студента: аватар, имя в игре, ввод собственных доходов, расходов, накоплений и долгов; свободный остаток и цель резерва.
- Интерактивные сценарии с ветвлением и образовательной обратной связью (шесть сценариев в четырёх модулях в прототипе).
- Серверный расчёт баланса, накоплений, долга, инфляции; хранение игровых сессий.
- Teacher Mode: статистика по студентам и группам, классификация ошибок, отчёты (CSV).
- Набор автоматических тестов, документация, диаграммы, результаты пилота.

## 1.5. Пользователи

| Роль | Потребность |
|---|---|
| Студент | Понятно и безопасно проверить решения о деньгах; увидеть последствия |
| Преподаватель | Видеть, в каких темах группа ошибается |
| Администратор | Управлять пользователями и сценариями |

## 1.6. Границы проекта (scope)

**Входит (MVP):** регистрация и вход; ввод личных финансов студентом; главный экран с модулями и личным планом; модуль «Личный бюджет»; модуль «Кредиты и рассрочка» с ветвлением и обратной связью; минимум один сценарий по распознаванию мошенничества; прогресс; обмен с сервером по REST API; базовые тесты.

**Расширения (только после MVP):** модуль «Накопления и инфляция» (сценарий уже есть в прототипе, в MVP не входит); полный набор аватаров и персонализация; достижения и рейтинг; полноценные экраны Teacher Mode; расширенный пилот.

**Платформа:** клиент — мобильное приложение на Flutter. Веб-версия прототипа используется только для демонстрации интерфейса на предзащите; перенос экранов во Flutter запланирован на дипломный этап.

**Не входит:** реальные финансовые операции и интеграция с банками; мультиплеер; публикация в магазинах приложений.

## 1.7. Сложность и научная новизна

Проект — клиент-серверная система с состоянием сессий, сценариями с ветвлением, серверным расчётом и защитой от подмены данных клиентом, разграничением трёх ролей и аналитикой. Новизна — сочетание сценарной симуляции с серверным расчётом последствий, локализации под Казахстан (тенге, местные продукты, схемы мошенничества) и Teacher Mode, выявляющего типичные ошибки группы.
