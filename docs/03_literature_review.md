## 3.1. Метод поиска

Поиск по ключевым словам: *serious games financial literacy*, *game-based learning financial education*, *gamification empirical effects*, *financial literacy economic outcomes*. Критерии отбора: рецензируемые статьи, обзоры и публикации 2014–2026 гг. (фундаментальные работы включены как исключение), релевантность теме игрового обучения финансам или геймификации.

## 3.3. Выводы из обзора

1. Финансовая грамотность связана с качеством финансовых решений, поэтому обучение должно работать с решениями, а не только со знаниями.
2. Геймификация даёт эффекты, но зависит от контекста и пользователей; поэтому проект строит полноценный сценарий, а не набор бейджей.
3. Качество дизайна серьёзных игр для финансов изучено слабо — это обоснование для собственной методики верификации ([08_verification_plan.md](08_verification_plan.md)).
4. Ограничения, которые учитывает проект: короткая длительность вмешательства, отсутствие данных по казахстанскому контексту, сложность оценки поведенческих эффектов.

## 3.4. Что остаётся открытым

- Нет данных по поведению студентов Казахстана в связке «игра → решения».
- Эффект долгосрочного обучения не измерен; в пилоте измеряется краткосрочный эффект.
