# 4. Сравнение существующих систем

Сравниваются 4 системы (требование: 3–5). Критерии (8, требование: 6–10) применяются одинаково ко всем системам. Оценки указываются только после проверки по официальным страницам или установке приложения; до проверки ячейка помечена **«проверить»**.

## 4.1. Системы для сравнения

| № | Система | Тип | Почему выбрана |
|---|---|---|---|
| S1 | Игры по финансовой грамотности для молодёжи (например, обучающие игры на английском, найденные в обзоре Aprea 2026) | Серьёзная игра | Прямой аналог по жанру |
| S2 | Онлайн-курсы и тесты по финансовой грамотности (MOOC-платформы, страницы госорганов и банков) | Курс / тесты | Основной текущий способ обучения |
| S3 | Личные финансовые приложения-трекеры (бюджет, расходы) | Приложение | Близко по теме личного бюджета, но без обучения |
| S4 | Учебный симулятор кредитов и рассрочки (банковские калькуляторы и симуляторы) | Калькулятор / симулятор | Близко по теме кредитов, но без сценариев и обратной связи |

Названия S1–S4 конкретизируются командой до предзащиты: для каждой системы нужно указать точное название, ссылку и дату проверки.

## 4.2. Критерии сравнения (8)

| К | Критерий | Что означает |
|---|---|---|
| C1 | Сценарии с ветвлением | Выбор игрока меняет дальнейший ход |
| C2 | Немедленная образовательная обратная связь | Пояснение после каждого решения |
| C3 | Локализация под Казахстан | Тенге, местные продукты, местные схемы мошенничества |
| C4 | Учёт прогресса и результатов | Сохранение сессий и показателей |
| C5 | Режим преподавателя (группы, статистика) | Видимость ошибок группы |
| C6 | Серверный расчёт последствий | Результаты не подделываются на клиенте |
| C7 | Мобильный интерфейс | Удобство на смартфоне |
| C8 | Открытость / возможность доработки | Можно ли адаптировать содержание |

## 4.4. Вывод

Ни одна из рассмотренных систем не сочетает сценарные решения, обратную связь, казахстанский контекст и режим преподавателя. Это и обосновывает разработку (после заполнения таблицы по факту).
