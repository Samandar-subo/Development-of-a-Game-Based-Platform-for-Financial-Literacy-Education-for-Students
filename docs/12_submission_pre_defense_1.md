## 12.3. Известные ограничения

- Серверной части нет; расчёты в клиенте локальные (временное решение).
- Во Flutter один сценарий; режима преподавателя нет; данные не сохраняются после закрытия.
- Интервью не проведены: есть только опрос из 8 человек (7 из 8 на третьем курсе), он не заменяет интервью.
- Эталонные значения расчётов не сверены консультантом по финансам.
- В сравнении систем Alatau City и BarsIQ не проверены за регистрацией; SPENT пройден на 3 днях из 30; FinPro осмотрен без прохождения уроков.
- Полные тексты источников 15, 16 и 18 не прочитаны.
- Отзыв руководителя на момент написания не получен.
- Тесты клиента v3 запускались авторами локально; результат записать в PR #13.
