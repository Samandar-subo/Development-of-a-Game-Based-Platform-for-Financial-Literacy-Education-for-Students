# Клиент (Flutter) — стартовый каркас

Задача: DIP-15 «Стартовый каркас Flutter-приложения» (ответственный — Самандар).

## Что есть

- `lib/main.dart` — точка входа, тема светлая и тёмная.
- `lib/theme.dart` — цвета и оформление, взятые из [prototype/index.html](../../prototype/index.html).
- `lib/screens/login_screen.dart` — экран входа и регистрации с проверкой полей.
- `lib/screens/onboarding_avatar_screen.dart` — шаг 1 онбординга: выбор персонажа (6 вариантов) и имени в игре.
- `lib/screens/onboarding_finance_screen.dart` — шаг 2: студент вводит доход, обязательные расходы, накопления и долги; свободный остаток считается сразу.
- `lib/screens/home_screen.dart` — главный экран: баланс, накопления, долг, личный план (резерв 3 месяца расходов), модули, кнопка «Продолжить игру», нижняя навигация. Значения берутся из введённого профиля.
- `lib/screens/scenario_screen.dart` — сценарий «Конец месяца»: два шага с ветвлением, обратная связь после каждого выбора, итог с ошибками и советами. Итог обновляет баланс, накопления и очки на главном экране.
- `lib/models/user_profile.dart`, `lib/utils/money.dart` — профиль студента, аватары, форматирование и разбор сумм в тенге.
- `test/widget_test.dart` — 7 тестов: ввод и проверка полей, онбординг с расчётом остатка, полный путь от входа до итога сценария.

## Чего пока нет

- Сервера: данные не отправляются, профиль и прогресс не сохраняются после закрытия приложения. Расчёты будут на сервере (FR-9).
- Остальных сценариев (шесть в прототипе, здесь один), режима преподавателя и итогового экрана по модулям.
- Экранов «Прогресс» и «Профиль»: вкладки нижней навигации есть, содержимого нет.
- Аватара-персонажа: вместо SVG из прототипа — эмодзи в цветном круге.
- Тёмной темы с переключателем в приложении: тема следует системной настройке телефона.

## Запуск

Архив для Android Studio: `finance_game_client.zip` (лежит рядом с папкой проекта, в репозиторий не коммитится). После распаковки открыть папку с `pubspec.yaml` через File → Open.

```bash
cd src/client
flutter pub get
flutter test
flutter run
```

Нужен Flutter SDK 3.27 или новее (используется `CardThemeData`).
